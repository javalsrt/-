# 课程笔记后端项目 —— 简单说明

这个项目是用 Java 写的后端程序，负责接收小程序和教师网页发来的请求，处理后把数据存到数据库或者返回给前端。

---

## 文件夹是干嘛的

项目里的代码都放在 `com/coursenote` 这个包里，下面分了几个文件夹：

- **common** —— 放一些整个项目都会用到的通用小工具
- **config** —— 各种配置，比如登录验证怎么配、数据库怎么连
- **controller** —— 处理前端发来的请求（比如访问网址、提交表单）
- **dto** —— 前端传过来的一堆参数，用这些类装起来，方便处理
- **entity** —— 和数据库表一一对应，表里有什么字段，这里就有什么属性
- **mapper** —— 负责跟数据库打交道，增删改查都是通过它
- **service** —— 干活的，实际的业务逻辑都写在这里
- **ws** —— 处理 WebSocket 长连接（AI 聊天用的）

### [JwtUtil.java](file:///c:/Users/jay/Desktop/作业/小林web大作业/course-note-backend/src/main/java/com/coursenote/config/JwtUtil.java)

## 7. service —— 干活的地方

业务逻辑都写在这里。每个 service 都分接口（定义能做啥）和实现类（具体怎么做）。

### UserService / UserServiceImpl
**用户相关的事情**：
- 微信登录：拿 code 去微信那边换 openid，老用户就登录，新用户就创建
- 查用户信息
- 更新用户信息

### CourseService / CourseServiceImpl
**课程相关的事情**：
- 获取课程表：根据学生所在的班级，匹配对应的课程，按星期一到日分组
- 创建、修改、删除课程
- 如果没有班级信息，返回空课表
- 没选颜色就用默认蓝色

### SessionService / SessionServiceImpl
**课段相关的事情**：
- 获取今天的课：先从课程表生成今天的课段，加上之前已经上过的课
- 开始上课、结束上课
- 查课段详情（带资料列表）
- AI 总结课段的资料
- 查某门课的历史课段

### MaterialService / MaterialServiceImpl
**资料相关的事情**：
- 上传照片：保存到本地 uploads 文件夹
- 创建文字笔记
- 导入外部资料
- 删除资料（检查是不是本人的）
- AI 处理资料：OCR 识别图片文字、生成标签、生成摘要

### KnowledgeBaseService / KnowledgeBaseServiceImpl
**知识库相关的事情**：
- 获取知识库列表
- 查知识库详情和文档
- 搜索知识库文档（关键词匹配）
- 把资料导入成知识库文档
- 提取关键词
- 学生只看自己的，互不干扰
- 老师能看所有学生的（按课程和班级聚合）

### AIService / AIServiceImpl
**跟 AI 大模型打交道的事情**：
- 聊天对话：先搜知识库，把相关文档拼到提示词里，再问 AI（RAG 检索增强）
- 文本总结
- 图片识别：调视觉模型看图片内容
- 文件上传到知识库：自动生成标题、标签
- 保存聊天记录
- 支持普通的和 WebSocket 两种对话方式

## 9. WebSocket —— AI 聊天长连接

### [ChatWebSocketHandler.java](file:///c:/Users/jay/Desktop/作业/小林web大作业/course-note-backend/src/main/java/com/coursenote/ws/ChatWebSocketHandler.java)

普通的 HTTP 请求是一问一答就断了，WebSocket 是连上后一直保持通话。AI 聊天就用这个。

大概流程：
1. 前端连上 `/ws/ai/chat`，携带登录 token
2. 后端验证 token，知道是谁在聊
3. 前端发消息过来，后端解析内容
4. 调 AI 服务去问大模型
5. 把 AI 回复往回发（先发"正在输入"，再发内容，最后发"完成"）
6. 把聊天记录存到数据库
7. 断开连接时清理资源

## 常见问题解释（带 API）

---

### Q1：学生怎么登录？

1. 小程序弹出微信授权，拿到 **code**
2. 把 code 发给后端

> **调用的 API：**
> `POST /user/login`
> 传的参数：`{ code: "wx...", nickname: "小明", avatarUrl: "https://..." }`

3. 后端拿 code 去微信服务器换 **openid**（相当于微信里的唯一证件号）
4. 用 openid 在数据库找用户 → 有就登录，没有就自动创建新用户
5. 生成一个 **token**（令牌）返回给小程序
6. 之后小程序访问其他接口，请求头里都要带上：`Authorization: Bearer {token}`

> **返回示例：**
> `{ code: 200, message: "success", data: { token: "xxx...", user: { id, nickname, avatarUrl, grade } } }`

---

### Q2：学生怎么查看课表？

> **调用的 API：** `GET /course/schedule?semester=2025-2026-1`

后端根据学生的班级（grade 字段），匹配对应班级的课程，按星期一到日分组返回。

> **返回示例：**
> `{ code: 200, data: { "1": [{name:"高数",startTime:"08:00",endTime:"09:40",...}], "2":[...], ... } }`

> **API：** `POST /session/end`

### Q4：学生怎么上传笔记/照片？

**上传照片：**

> **API：** `POST /material/upload`（form-data）
> 参数：`sessionId=1`, `courseId=1`, `file=图片文件`

**写文字笔记：**

> **API：** `POST /material/note`
> 参数：`{ sessionId: 1, courseId: 1, title: "重点", content: "今天讲了..." }`

**查看资料：**

> **API：** `GET /material/session/{sessionId}`

**删除资料：**

> **API：** `DELETE /material/{id}` — 只能删自己上传的

**让 AI 识别图片：**

> **API：** `POST /material/process-ai`
> 参数：`{ materialId: 1 }`

### Q5：上传文件到知识库发生了什么？

> **API：** `POST /ai/knowledge/upload`（form-data）
> 参数：`file=文件`, `courseId=1`, `sessionId=1`

1. 后端把文件保存到服务器硬盘
2. 如果是图片 → 调视觉模型识别内容；其他文件 → 记录基本信息
3. 自动给文件起标题、打标签
4. 创建知识库（不存在就新建） → 创建文档记录 → 标记为"已完成索引"

---

### Q6：跟 AI 聊天是怎么"记住"知识库的？

**WebSocket 方式（小程序用）：**

> **连接：** `ws://你的服务器/ws/ai/chat?token={token}`
> **发送：** `{ message: "高数考试重点?", courseId: 1, sessionId: 1 }`

1. 后端收到消息 → 提取关键词 → 搜知识库文档 → 拼成上下文
2. 把"文档内容 + 问题"一起发给 AI 大模型
3. 收到 AI 回复后逐条返回（"正在输入"→ 内容 → "完成"）
4. 聊天记录自动保存到 `ai_chat_record` 表

**HTTP 方式（备用）：**

> **API：** `POST /ai/chat`
> 参数：`{ message: "...", courseId: 1, history: [...], useKnowledgeBase: true }`

### Q9：教师仪表盘的数据是怎么来的？

> **API：** `GET /teacher/dashboard`

1. 先找老师教的班级 → 再找这些班的所有课程
2. 统计选了这些课的学生的：资料数、文档数、AI提问数
3. 汇总 + 近30天趋势

| 其他统计接口 | 作用 |
|------------|------|
| `GET /teacher/stats/material-trend` | 近30天资料上传趋势 |
| `GET /teacher/stats/ai-trend` | 近30天AI提问趋势 |
| `GET /teacher/stats/course-stats` | 按课程统计 |
| `GET /teacher/stats/participation` | 学生参与度（谁从未上传过） |
